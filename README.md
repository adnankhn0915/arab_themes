# Arab Themes

A custom Frappe app that ships three pre-built Arabic-themed website themes and a
small theme-switcher widget so users can switch between them from the website
settings / a switcher control.

## Themes

- **Arabic Classic** — warm sand tones, traditional feel.
- **Arabic Modern** — deep navy, contemporary.
- **Arabic Midnight** — dark, low-glare theme.

## Install

```
bench install-app arab_themes
bench migrate
```

After install, open **Website Settings** and set the default **Website Theme** to
one of the three Arab Themes. Switching is done via the **Theme Switcher** widget.
